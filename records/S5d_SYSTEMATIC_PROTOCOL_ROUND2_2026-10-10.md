# S5d 协议：对照规格的系统抽样，第二轮判据（2026-10-10）

首轮（`S5b` 协议 + `S5c` 结果）用的判据是"读者能否从论文文本判断对照的额外参数
是否影响输出"，结果 4 篇纳入论文的 5 条陈述**全部可检验、零条不可检验**，
按 S5b §5 的预先规则判"不支持 C6 的领域性主张"。

但首轮同时查出一条更尖锐的东西，记在 S5c §4.2：

> 首轮 4 篇里有 2 篇出现同一形态：**规格给足了，但匹配本身没有被执行或对不上账。**

本协议把那条提为第二轮的主判据。**本文在查看任何第二轮论文之前写定。**

不改动预注册协议，不构成执行授权，未动用 test 或 external_test。

---

## 0. 与首轮的关系，三条硬约束

1. **不得用首轮数据回测。** S5c 的 4 篇及其 5 条陈述**全部排除**在第二轮抽样框之外。
   理由：新判据正是从那两篇身上看出来的，拿它们回测等于用发现判据的样本验证判据。
2. **首轮的 A/B/C 三分不作废，但降为附记。** 第二轮对每篇仍记 A/B/C，
   只是判定不再由它决定。两套标签并列落盘，便于日后合并分析。
3. **首轮的"不支持"判定不因第二轮而改写。** 第二轮若发现大量对不上账的实例，
   那支撑的是一条**新主张**（见 §5），不是把 C6 的领域性主张救回来。
   把两者混为一谈即为事后改判。

## 1. 新判据：论文自己的公式与论文自己报告的数字是否对得上

### 1.1 为什么这个判据更好

首轮判据问的是"规格是否充分"，它的毛病在 S5c §1.1 的注里已经暴露：
**同一条陈述，我判 A、检索工具判 B 或 C**，因为"足以判断"是一个程度判断。

新判据问的是一个**算术问题**：

> 论文给出了对照的函数形式（或指明了标准组件），也给出了各变体的参数量。
> **按它自己给的形式算出来的参数量，与它自己报告的参数量，是否一致？**

读者不需要读代码，不需要补充假设，也不需要判断"足以"到什么程度。
对不上即构成一个可指出的事实。

### 1.2 判据的正式形式，在抽样前写死

对每篇纳入论文的每一条参数匹配陈述，归入且仅归入一类：

| 标签 | 定义 | 判定方式 |
|---|---|---|
| **R 对得上** | 按论文给出的形式推算的参数量，与论文报告的数值在**取整误差**内一致 | 推算过程须在结果文件中逐步写出 |
| **D 对不上** | 推算值与报告值**不一致**，且论文正文未解释差额 | 须写明推算值、报告值、差额 |
| **E 无法推算** | 论文未给出足以推算的形式，或未报告可比的参数量 | 不构成 D，另记 |

**取整误差的定义，写死：** 报告值以 M（百万）为单位给出一位小数时，
容差为 ±0.05M；给出整数 M 时容差为 ±0.5M；给出精确整数参数量时容差为 0。

**一条预先声明：** 标签 D **不等于论文有错**。差额可能来自论文未提及的实现细节
（偏置项、归一化层、投影层）。D 的含义是**读者无法从论文核对这个匹配**，
与首轮测量"可检验性"同向，但判定方式由程度判断变成算术。
任何把 D 读作"该论文造假"或"该对照退化"的引用都是误用，论文中须写明这一点。

### 1.3 不做的事

**不点名指认任何已发表论文的对照是退化的。** 这条从 S5 §0.3 起一直有效，
本轮不变。D 类实例在结果文件中按编号与 arXiv 号记录，
论文正文中只报比例与至多两个**已自行承认或差额由论文自己点明**的例子。

## 2. 抽样框

**总体**：提出一个含可学习参数的模块或算子，**同时**满足

1. 给出该模块与其对照的函数形式（公式，或指明标准组件）；
2. 报告两者的参数量（表中并列即算）。

**排除**：S5c 已编码的 4 篇；综述与立场文章；只比超参数而无对照语义者。

**检索途径**：限定 `arxiv.org`，查询词在本文定稿时写定，执行时不增不减：

1. `ablation "parameter count" table gating module neural network`
2. `"we reduce the" width "same number of parameters" ablation`
3. `ablation baseline "matched parameter count" formula`
4. `"additional parameters" ablation module parameter count table`
5. `pooling operator ablation learnable parameter count comparison`

第五条刻意指向本项目的最近邻族。**首轮两篇因只有 PDF 而不可获取**
（arXiv 1910.06764、2109.01561），本轮若再遇同样情形仍按"不可获取"计数并报告数量，
不替换为别的论文。

## 3. 样本量与停止规则

**目标 12 篇纳入论文。** 低于首轮的 24，理由写在这里：

- 新判据要求逐篇做一次参数量推算，单篇成本显著高于首轮的标签判断；
- 首轮已证明在单一编码者下把 n 做大不改善编码者效应（S5c §3.1）；
- **12 篇配一次独立复核，优于 24 篇无复核。**

**停止规则**：达到 12 篇纳入，或五个查询词的可得结果处理完毕，以先到者为准。
实际纳入数少于 12 时如实报告，不补充查询词。

**编码者**：本轮仍预期为单一编码者。**这是本研究的主要局限，须与结果并列陈述。**
若能引入第二位编码者，**优先把人力用于复核已有编码，而不是扩大 n**。

## 4. 结果的预先解读规则

写在抽样之前。分母为 R 与 D 之和，**E 类不进分母**（无法推算者不构成对不上账的证据）。

| 实测 D 类比例 | 含义 |
|---|---|
| **≥ 40%** | 强支持：参数匹配陈述与报告数字对不上账是常见情形 |
| **15% 至 40%** | 支持：相当比例对不上账 |
| **5% 至 15%** | 弱：存在但不常见，只能作为个案报告 |
| **< 5%** | **不支持**：对不上账是罕见情形，本条不得作为论文主张 |

**E 类比例另行报告**，并预先声明其含义：E 类高说明"连推算所需的信息都没有给"，
这回到首轮的可检验性问题，**不得与 D 类合并计数**来做大分子。

## 5. 这一轮支撑的是哪条主张，先说清楚

**不是 C6。** C6 说的是"按计数匹配的对照会让对比偏向被检方法"，
其领域性主张已按首轮结果撤回，本轮不碰。

本轮支撑的是一条新主张，暂记为 **C10**：

> 参数匹配是一个**读者可以自行核对但通常没人核对**的断言。
> 论文给出公式，也给出数字，两者是否自洽不需要代码即可验算，
> 而这一步不在任何审稿流程的要求里。

C10 与 C4、C6、C7 的共同形状一致（见 P3 §三），但它比那三条更强一点：
**它所需要的检验，读者手里的材料已经够了。** C4 需要重跑，C7 需要数 group，
C6 需要读实现，而 C10 只需要一次乘法。
