# S5b 协议：对照规格的系统抽样，判据与抽样框（2026-10-10）

`S5_CONTROL_SPECIFICATION_LITERATURE_AUDIT_2026-09-25.md` 是定向审计，
明确声明过"本文的结论是关于表述与规定方式的，不是关于文献中有多少比例的对照是退化的"。
本文把那半句补上：系统抽样，回答比例问题。

**本协议在查看任何论文之前写定。** 判据、抽样框、分类标签、样本量、
以及"什么结果算支持主张、什么算不支持"全部在此固定。理由见 §0。

不改动预注册协议，不构成执行授权，未动用 test 或 external_test。

---

## 0. 为什么必须先写协议

C6 的主张是"按计数匹配的对照会让对比偏向被检方法"。若我边看论文边定判据，
就会挑出支持该主张的例子。**这正是本项目主线 B 所批评的做法**，
在用来支撑 C6 的证据上犯它尤其不可接受。

因此本文先固定一切可选项，再采样。采样过程中若发现判据无法执行，
按 §6 的程序修订并记录，不得静默调整。

## 1. 问题的重新表述，这是本协议的关键决定

直接问"有多少已发表对照的额外参数梯度恒为零"**不可执行**：
判定需要读到实现或完整前向表达式，而多数论文不提供。
S5 §0.3 已据此拒绝点名指认任何论文。

**本协议改问一个可执行且更有力的问题：**

> 当一篇论文声称其消融对照与被检方法"参数匹配"时，
> 读者能否从论文给出的信息判断该对照的额外参数是否影响输出？

这个问题可由论文文本回答，不需要代码，也不需要指认任何论文有缺陷。
而它的答案直接支撑 C6 的核心：**如果多数情况下读者无法判断，
那么"参数匹配"这一说法在当前报告惯例下是不可检验的断言**，
与 C7（分层条件不可检验）、C4（验收标准被伪影满足）构成同一主题。

## 2. 抽样框

**总体**：提出一个含可学习参数的模块或算子、并在消融中报告一个
声称与之在参数量上可比的对照的论文。

**检索途径**：公开网络检索，查询词围绕以下表述的组合，
全部在本文定稿时写定，执行时不增不减：

1. `"parameter-matched" ablation`
2. `"same number of parameters" ablation baseline`
3. `"comparable number of parameters" ablation`
4. `"equal parameter count" ablation control`
5. `ablation "parameter-free" variant same capacity`

**纳入标准**，三条全部满足：

- 论文提出至少一个含可学习参数的模块；
- 消融表或正文中出现对照与被检模块参数量可比的陈述；
- 可获取论文正文或足以判断 §3 分类的方法描述。

**排除标准**：

- 综述与立场文章；
- 只比较不同超参数（如层数、宽度）而无"对照"语义者；
- 仅有摘要可得、无法判断 §3 分类者，计入"不可获取"并报告其数量。

## 3. 分类标签，三类，互斥且穷尽

对每篇纳入论文的每一条参数匹配陈述，归入且仅归入一类：

| 标签 | 定义 | 判定方式 |
|---|---|---|
| **A 可检验** | 对照的函数形式给出到足以判断其每个额外参数是否影响输出的程度，例如给出完整公式或明确的"该参数不参与前向"之类陈述 | 读者可直接推导梯度是否恒为零 |
| **B 不确定** | 对照以散文描述，形式可推测但不唯一，需要补充假设才能判断 | 存在两种以上合理读法，其中至少一种会导致额外参数无效 |
| **C 不可检验** | 只断言参数量相同或相近，未给出对照的函数形式 | 无论如何读都无法判断 |

**预先声明**：标签 A 不等于"该对照正确"，标签 C 不等于"该对照错误"。
本协议测量的是**可检验性**，不是正确性。任何把 C 读作"有缺陷"的引用都是误用，
论文中须写明这一点。

## 4. 样本量与停止规则

**目标 24 篇纳入论文**，按 §2 的五个查询词各取前若干条结果，
按检索返回顺序处理，不跳过任何满足纳入标准者。

**停止规则**：达到 24 篇纳入，或五个查询词的可得结果全部处理完毕，
以先到者为准。实际纳入数少于 24 时如实报告，不补充查询词。

**双重编码**：本轮由单一编码者执行，无法做编码者间一致性。
**这是本研究的主要局限，须在论文中与结果并列陈述**，不得只报比例。

## 5. 结果的预先解读规则

写在采样之前，防止事后挑选解读方式。

| 实测 C 类比例 | 对 C6 的含义 |
|---|---|
| **≥ 50%** | 支持主张：多数参数匹配陈述在当前惯例下不可检验 |
| **20% 至 50%** | 部分支持：相当比例不可检验，但不构成"惯例性" |
| **< 20%** | **不支持**：多数论文给出了足以检验的信息，C6 应降级为"本项目内的四个实例"，不得声称领域性 |

## 6.2 一条执行纪律

检索引擎返回的摘要会**自行做出判断**，例如"参数量保持可比"或
"结果未显示是否测试了参数匹配基线"。**不得按检索摘要编码。**
每个标签必须由论文正文的方法或消融段落支撑，并在结果文件中附原文片段。
无法获取正文者按 §2 计入"不可获取"。

## 6.3 两条解释规则（2026-10-10，编码第一篇后记录）

**规则一：命名标准组件等同于给出函数形式。** §3 的标签 A 写的是
"给出到足以判断其每个额外参数是否影响输出的程度，例如给出完整公式"，
"例如"是举例而非唯一方式。若对照被指明为某个标准组件（如"增加 KV 头数"、
"增加专家数"），其计算由该组件的通行定义确定，读者可据此判断参数是否影响输出，
**归入 A**。仅当对照除"参数量相同"之外未被识别时才归入 C。

**规则二：新增一个正交维度，记录匹配是如何达成的。** 编码第一篇
（arXiv 2505.06708）时发现存在一种本协议 §1 未设想的做法：
**通过缩小被检方法来匹配，而非给对照加参数**（原文："When using gating,
we reduce the FFN's width so that all methods have the same number of parameters"）。
这种做法从构造上避免了死参数。

因此每条陈述除 A/B/C 标签外，另记一个匹配方式标签：

| 方式 | 含义 | 是否可能产生死参数 |
|---|---|---|
| **S 缩小法** | 缩小被检方法以匹配对照 | 不可能，对照未被改动 |
| **P 加法** | 给对照增加参数以匹配被检方法 | **可能**，这是 C6 所指的情形 |
| **U 未说明** | 文本未说明如何达成 | 不可判 |

这个维度不改变 §5 的三档解读规则，它是附加信息。
但它可能改变 C6 的表述：若文献中 S 法常见，则 C6 应从
"人们做错了"改为"存在正确做法与错误做法，而报告惯例通常不让读者分辨是哪一种"。
该判断待 §8 的结果汇总后作出，不在此预断。

## 6.4 纳入边界的放宽，与一条意外发现（2026-10-10，编码第三篇后）

**遇到的情形。** arXiv 2509.12817（SAGA）在消融表中**列出**各变体的参数量
（26M、27M、28M、29M）却**不声称**它们匹配，文本也未描述任何匹配程序。
§2 的纳入标准要求"出现对照与被检模块参数量可比的陈述"，严格读会排除它。

**放宽后的标准。** 在消融表中并列报告对照与被检模块的参数量，
即构成可比性的隐含主张，纳入。理由：这是该惯例的实际运作方式——
并列参数量正是为了让读者认为比较是公平的。
排除它会把最常见的情形排除在总体之外。

**同时新增一个方式标签取值：** 除 S、P、U 之外，增加

| 方式 | 含义 |
|---|---|
| **N 未匹配** | 并列报告了参数量，但各变体的数值不同且未声称匹配 |

SAGA 属 N：26M 对 28M 相差 2M，文本未解释。

### 6.4.1 一条意外发现：判据本身难以干净应用

**前三篇里有两篇触发了协议修订**（§6.3 规则一、本节）。这不是协议写得差，
而是"参数匹配"这一说法在文献中的形态比预期多样：它可以通过缩小被检方法达成、
通过给对照加参数达成、通过并列报告不匹配的数值暗示、或完全不说明。

**这一点本身是 C6 的证据，而且是比比例更强的证据。** 一个在运行前写定判据、
并且专门为检验此事而设计的编码方案，在前三篇里就两次需要修订边界，
说明"参数匹配"在当前惯例下**不是一个有确定含义的断言**。

这条发现须与 §5 的比例结果并列报告，且**不得用它替代比例结果**——
比例仍按 §5 的三档判定。
